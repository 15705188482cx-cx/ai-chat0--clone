# 微信聊天记录导出教程

## 方法一：使用 WeChatMsg（推荐）

1. 下载 WeChatMsg 工具：https://github.com/LC044/WeChatMsg
2. 按工具说明解密并导出微信聊天记录
3. 导出格式选择 **JSON** 或 **TXT**
4. 将导出文件传输到手机

## 方法二：微信原生导出

1. 打开微信 → 进入目标聊天
2. 点击右上角 "..." → "查找聊天记录"
3. 选择需要导出的日期范围
4. 通过邮件或文件传输助手将记录发送到手机

## 支持的格式

- TXT（微信原生导出风格）
- JSON（WeChatMsg 工具导出）
