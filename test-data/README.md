# AI 聊天分身 —— 测试数据说明（恋人场景）

## 场景设定

这是一对情侣 2024 年第一季度的微信聊天记录。用户（"我"）与女友（"她"）分手后，通过导入这段记录，让 AI 学习"她"的说话风格，实现虚拟伴侣功能。

## 概览

| 文件 | 格式 | 消息数 | 时间跨度 | 用途 |
|------|------|--------|----------|------|
| `chat_full.txt` | 微信原生 TXT 导出 | 319 条 | 2024-01-01 ~ 2024-03-30 (3个月) | 完整功能测试 / AI 风格学习 |
| `chat_full.json` | WeChatMsg JSON 格式 | 319 条 | 同上 | 解析器验证 / 导入流程测试 |
| `chat_quick.txt` | 微信原生 TXT 导出 | 50 条 | 2024-03-25 ~ 2024-03-31 (1周) | 快速解析验证 |
| `chat_quick.json` | WeChatMsg JSON 格式 | 50 条 | 同上 | 快速导入流程测试 |
| `generate.py` | Python 脚本 | — | — | 重新生成数据（seed=42 可复现） |

## 参与人物

### "她"（AI 模仿目标）

| 特征 | 说明 |
|------|------|
| **语气** | 亲密可爱、撒娇、热情 |
| **常用 Emoji** | 😊🥺❤️😘😂🙈✨💕😋🌙🎉 |
| **高频词** | 呜呜、嗯嗯、好呀、想你了、抱抱、亲亲、乖乖 |
| **句子风格** | 短句为主、叠词频繁、爱用感叹号和问号连用（"真的吗!!""好呀好呀"） |
| **行为模式** | 主动分享日常、追问对方状态、偶尔发 [图片] 分享生活 |
| **发送占比** | 58%（185 条） |

### "我"（用户角色）

| 特征 | 说明 |
|------|------|
| **语气** | 正常男性、偏内敛、偶尔宠溺 |
| **行为模式** | 回应宠溺但话少、偶尔主动关心、吵架时先服软 |
| **发送占比** | 42%（134 条） |

## JSON 格式说明

```json
{
  "sender_name": "我",       // 必填，"我" 或 "她"
  "content": "早啊 起床了吗", // 消息内容，Emoji 直接保留
  "time": "2024-01-15 09:30:00",  // 时间戳
  "type": "text"              // "text" 或 "image"
}
```

- type="image" 的消息仅包含 `[图片]` 占位符，解析时被 messageCleaner 过滤，不参与 AI 风格学习
- 所有其他消息 type="text"，直接用于 Few-shot Prompt 构建
